# 🌟 Live2D AI Assistant — Ваш Персональный Интерактивный Ассистент 🌟

**Live2D AI Assistant** — это не просто чат-бот, а полноценный **живой персонаж**, который поселится на вашем компьютере. Создайте ассистента с уникальным характером, внешностью и голосом, и он будет вести с вами осмысленный диалог, запоминать контекст беседы, реагировать на ваши действия и даже скучать, если вы о нем забудете.

Приложение работает **полностью локально**, обеспечивая абсолютную приватность ваших данных и независимость от облачных сервисов.

## 🚀 Ключевые Достоинства и Новые Возможности

Этот проект был значительно переработан и теперь обладает функциями, которые делают его по-настоящему живым и интерактивным:

### 🎭 Продвинутое Управление Персонажами
-   **Менеджер Ассистентов:** Создавайте, редактируйте и удаляйте неограниченное количество ассистентов через удобный веб-интерфейс.
-   **Глубокая Кастомизация:** Для каждого ассистента можно задать уникальный **системный промпт**, **Live2D-модель**, **голос**, **масштаб**, **позицию на экране** и **глубину памяти**.
-   **Система Чатов:** Ведите отдельные, изолированные диалоги с разными ассистентами или с одним и тем же персонажем в разных контекстах.

### ✨ Глубокая Интерактивность
-   **Динамические Команды:** Управляйте поведением модели прямо из чата с помощью скрытых команд (`【...】`). Ассистент может **смотреть по сторонам**, **наклонять голову**, **закрывать глаза** и выполнять комплексные **анимации кивка или мотания головой**.
-   **Накопление и Сохранение Состояния:** Позы, заданные командами, **комбинируются и сохраняются** на несколько сообщений, создавая эффект продолжительного действия, а не мгновенной реакции.
-   **Реакция на Поглаживания:** Если погладить ассистента в области головы дольше 3 секунд, он "запомнит" это и сможет **отреагировать на ваше действие** в своем следующем ответе.
-   **"Живая" Система Скуки:** Ассистент может сам начать диалог, если вы долго неактивны. Вы можете задать список фраз или **позволить нейросети генерировать их на лету**, основываясь на характере персонажа и истории чата!

### 💻 Улучшенный Пользовательский Опыт
-   **Редактирование и Удаление Сообщений:** Полный контроль над историей диалога с помощью удобного контекстного меню.
-   **Персонализация Профиля:** Ассистент **знает, как вас называть и кто вы**, используя информацию из вашего профиля для более личного и глубокого общения.
-   **Голосовой Ввод и Озвучка:** Взаимодействие голосом с качественным распознаванием (**Whisper**) и синтезом речи (**Silero**).

## 🛠️ Технологический стек

-   **Бэкенд:** Python + FastAPI (WSGI-bridge для Flask) + SQLAlchemy
-   **Фронтенд:** HTML, CSS, JavaScript
-   **База данных:** SQLite
-   **LLM (Мозг):** [LM Studio](https://lmstudio.ai/) (как локальный сервер для любой GGUF-модели)
-   **TTS (Голос):** [Silero Models](https://github.com/snakers4/silero-models)
-   **STT (Уши):** [OpenAI Whisper](https://github.com/openai/whisper)
-   **Анимация:** [Live2D Cubism SDK for Web](https://www.live2d.com/en/sdk/cubism-sdk/cubism-sdk-for-web/) + [PixiJS](https://pixijs.com/)

## 📋 Предварительные требования

Перед установкой убедитесь, что у вас есть:

1.  **Python 3.9+**.
2.  **LM Studio:** Установленное приложение, с загруженной и готовой к работе моделью (например, `google/gemma-2-9b-it-gguf`).
3.  **ffmpeg:** Убедитесь что у вас скачана папка ffmpeg "Live2DAssistant\ffmpeg" со всеми необходимыми файлами.
4.  **Производительный ПК:** Желательно с современной видеокартой NVIDIA (**6GB+ VRAM**) для комфортной работы нейросетей.

## ⚙️ Установка и Запуск

Процесс установки стал невероятно простым благодаря удобному лаунчеру!

### Шаг 1: Скачайте и распакуйте проект
Скачайте все файлы проекта и распакуйте архив в удобное для вас место.

### Шаг 2: Подготовьте модели

-   **Live2D Модели:** Внутри папки `static/` создайте директорию `Live2d_Models`. Внутри нее создайте отдельные папки для каждой вашей модели (например, `Hiyori`, `Liliana`) и поместите туда соответствующие файлы.
-   **Голосовые модели Silero:** Внутри папки `static/` создайте директорию `silero_models` и поместите в нее скачанные `.pt` файлы моделей (например, `v4_ru.pt`).
-   **FFmpeg:** В корне проекта создайте папку `ffmpeg` и скопируйте в нее `ffmpeg.exe` и `ffprobe.exe`.

### Шаг 3: Запуск!

1.  **Запустите LM Studio:** Откройте приложение, выберите нужную модель и **запустите локальный сервер** на вкладке `<->`.
2.  **Запустите `run.bat`:** Просто **дважды кликните по файлу `run.bat`**.

> **Это всё!** Лаунчер `run.bat` автоматически выполнит все необходимые действия:
> -   Активирует виртуальное окружение `venv`.
> -   Проверит и установит все недостающие Python-библиотеки из `requirements.txt`.
> -   Запустит Python-сервер `python_server.py` через Uvicorn.
> -   Автоматически откроет приложение в вашем браузере.

Наслаждайтесь общением с вашим персональным AI ассистентом!


## 🔌 Связь двух локальных серверов (чат + сайт с шашками)

Добавлен API-маршрут для интеграции второго сайта (например, игры в шашки) с ассистентом:

- `POST /api/bridge/chat` на сервере ассистента (порт `5000`)
- Пример прокси-сервера игры: `integration_demo/checkers_bridge_server.py` (порт `5001`)

Пример запроса на сервер ассистента:

```json
{
  "assistant_id": 1,
  "session_id": "checkers-room-42",
  "message": "Что мне лучше сделать в этом ходу?",
  "game_context": {
    "best_move": "b6-a5",
    "max_captures_now": 2,
    "position_fen": "W:W18,22:B9,13",
    "difficulty": "normal"
  }
}
```

Где:
- `chat_id` — опционально (если передан, используется существующий чат);
- `assistant_id` + `session_id` — опционально, но удобно для второго сайта: сервер сам найдёт или создаст bridge-чат;
- `game_context` автоматически добавляется в контекст LLM вместе с сообщением игрока.

## 📂 Структура проекта

```
/Live2D-Assistant/
|
|-- /ffmpeg/ # Исполняемые файлы ffmpeg
|-- /static/
| |-- /Live2d_Models/ # Папки с вашими Live2D моделями
| |-- /Live2d_avatars/ # Загружаемые вручную через сайт фото с вашими Live2D моделями
| |-- /silero_models/ # Файлы голосовых моделей Silero
| |-- /img/ # Используемые картинки кнопок и аватара для сайта
| |-- script.js # Основная логика фронтенда чата
| |-- edit_assistant.js # Логика для страницы редактора
| |-- style.css # Стили
|
|-- /templates/
| |-- base.html # Базовый HTML-шаблон
| |-- index.html # HTML-страница чата
| |-- edit_assistant.html # HTML-страница редактора
|
|-- /venv/ # Виртуальное окружение
|-- /integration_demo/ # Пример второго локального сервера (шашки -> ассистент)
|
|-- app.py # Основной код бизнес-логики и Flask-маршрутов
|-- python_server.py # Точка входа Python-сервера (FastAPI + Uvicorn)
|-- config.py # Файл с базовыми настройками (URL сервера)
|-- requirements.txt # Список Python-библиотек
|-- database.db # Локальная база данных
|-- run.bat # Удобный лаунчер для Windows
```

## 🔧 Кастомизация

Забудьте о редактировании `config.py` для настройки персонажей! Вся кастомизация теперь происходит в удобном веб-интерфейсе:

-   **Меню (☰) -> Ассистенты:** Здесь вы можете **создать нового ассистента** или нажать на существующего, чтобы перейти в **режим редактирования**.
-   В редакторе вы можете изменить **всё:** от имени и системного промпта до Live2D-модели, голоса и тонких настроек анимации рта. Экспериментируйте и создавайте уникальных персонажей!
