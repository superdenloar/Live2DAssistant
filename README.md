# 🌟 Live2D AI Assistant — Ваш Персональный Интерактивный Ассистент 🌟

**Live2D AI Assistant** — это не просто чат-бот, а полноценный **живой персонаж**, который поселится на вашем компьютере. Создайте ассистента с уникальным характером, внешностью и голосом, и он будет вести с вами осмысленный диалог, запоминать контекст беседы, реагировать на ваши действия и даже скучать, если вы о нем забудете.

В качестве мозгового центра теперь используется мощный облачный сервис **Elysium AI** с моделью **Antigravity 4 (`deepseek-v4-flash`)**, обеспечивающий быстрые, умные и эмоциональные ответы без необходимости нагружать видеокарту тяжелыми локальными моделями. При необходимости сохранена возможность переключения на локальный **LM Studio**.


## 🆕 B2B-кабинет (версия MVP)

После запуска `run.bat` откройте **http://127.0.0.1:5000** — там теперь лендинг продукта.
Кнопка «Войти» открывает окно входа: регистрация пока «в разработке», а ниже есть кнопка **«Войти как администратор»**.

Разделы кабинета (`/app/...`):
- **Ассистенты** — карточки персонажей, создание с выбором типа: Live2D, GIF / PNG-тубер, чат-бот без аватара (3D VRM, видео-аватар и голосовой агент помечены «В разработке»).
- **Редактор** — живое превью, вкладки «Основное / Внешность / Голос / Поведение / Виджет», сохранение без перезагрузки (Ctrl+S).
- **Диалоги** — все разговоры из студии и с сайтов. Посетитель может позвать оператора (кнопка с гарнитурой в виджете или фраза «позовите оператора») — диалог поднимается наверх, и вы отвечаете вместо ассистента.
- **Аналитика** — сообщения по дням, доля ответов без оператора, нагрузка по часам (есть переключатель демо-данных).
- **Документация** — код встраивания, контекст страницы, JS API виджета (`LW.open / ask / say / callOperator`), REST API.
- **Настройки** (нейросеть и уведомления), **Подписка** (тарифы, расход), **Аккаунт** (аватарка администратора, профиль).
- **Студия** (`/studio`) — прежний полноэкранный чат с персонажем.
- **Демо-сайт** (`/demo`) — магазин чая с установленным виджетом, чтобы проверить всё глазами клиента.

### GIF-ассистент
Работает как `example.py`, но в браузере и от голоса ассистента: загрузите GIF, где первый кадр — рот закрыт, а последний — открыт.
Номер кадра выбирается по громкости речи со сглаживанием и автоподстройкой потолка. Второй режим — две картинки «молчит / говорит».
Кадры раскладывает сервер (нужен `Pillow`, добавлен в `requirements.txt`); если его нет — браузер сделает это сам.

### Шашки (`run_checkers.bat`)
Полные правила русских шашек (бить назад, дальнобойные дамки, превращение во время взятия, «турецкий удар», ничьи),
движок с перебором вариантов в Web Worker и три уровня бота. Ассистент получает оценку позиции, лучший ход, главный вариант
и разбор последнего хода пользователя — и советует только реальные ходы. Кнопка «Спросить тренера» задаёт вопрос ассистенту.

## 🚀 Ключевые Достоинства и Новые Возможности

### 🧠 Мощный интеллект на базе Elysium AI & DeepSeek V4 Flash
-   **Elysium AI интеграция:** Быстрый доступ к передовой модели `deepseek-v4-flash` через единый OpenAI-совместимый API (`https://elysiumai.garden/v1`).
-   **Гибкая настройка ключа API:** Вставляйте и сохраняйте свой API-ключ прямо в веб-интерфейсе через удобную вкладку **«Нейросеть (API)»** или в файле `config.py`.
-   **Проверка подключения в один клик:** Кнопка «⚡ Проверить» тестирует ключ и модель перед началом общения.
-   **Автоматическая очистка размышлений:** Блоки внутреннего рассуждения `<think>...</think>` автоматически скрываются из чата и не мешают синтезу речи.
-   **Альтернативные провайдеры:** Вы можете легко переключиться обратно на локальный LM Studio или любой другой OpenAI-совместимый сервер.

### 🎭 Продвинутое Управление Персонажами
-   **Менеджер Ассистентов:** Создавайте, редактируйте и удаляйте неограниченное количество ассистентов через удобный веб-интерфейс.
-   **Глубокая Кастомизация:** Для каждого ассистента можно задать уникальный **системный промпт**, **модель нейросети**, **Live2D-модель**, **голос**, **масштаб**, **позицию на экране** и **глубину памяти**.
-   **Система Чатов:** Ведите отдельные, изолированные диалоги с разными ассистентами или с одним и тем же персонажем в разных контекстах.

### ✨ Глубокая Интерактивность
-   **Динамические Команды Live2D:** Управляйте поведением модели прямо из чата и промптов с помощью команд (`【...】`). Ассистент может **смотреть по сторонам**, **наклонять голову**, **закрывать глаза** и выполнять анимации **кивка или покачивания головой**.
-   **Накопление и Сохранение Состояния:** Позы, заданные командами, комбинируются и сохраняются на несколько сообщений.
-   **Реакция на Поглаживания:** Если погладить ассистента в области головы дольше 3 секунд, он запомнит это и отреагирует в своем следующем ответе.
-   **"Живая" Система Скуки:** Ассистент может сам начать диалог, если вы долго неактивны.

### 💻 Пользовательский Опыт
-   **Редактирование и Удаление Сообщений:** Полный контроль над историей диалога через контекстное меню.
-   **Персонализация Профиля:** Ассистент знает ваше имя и описание из профиля.
-   **Голосовой Ввод и Озвучка:** Распознавание речи (**Whisper**) и синтез речи (**Silero TTS**).

## 🛠️ Технологический стек

-   **Бэкенд:** Python + FastAPI (WSGI-bridge для Flask) + SQLAlchemy
-   **Фронтенд:** HTML, CSS, JavaScript
-   **База данных:** SQLite
-   **LLM (Мозг):** [Elysium AI](https://elysiumai.garden) (модель `deepseek-v4-flash`) / LM Studio
-   **TTS (Голос):** [Silero Models](https://github.com/snakers4/silero-models)
-   **STT (Уши):** [OpenAI Whisper](https://github.com/openai/whisper)
-   **Анимация:** [Live2D Cubism SDK for Web](https://www.live2d.com/en/sdk/cubism-sdk/cubism-sdk-for-web/) + [PixiJS](https://pixijs.com/)

## 🔑 Настройка API Elysium AI

1. Зарегистрируйтесь на платформе **[Elysium AI](https://elysiumai.garden)** и скопируйте свой API-ключ вида `sk-...`.
2. Запустите приложение через `run.bat`.
3. Откройте боковое меню **☰ -> вкладка «Нейросеть (API)»**.
4. Вставьте ваш ключ в поле **API Ключ**.
5. Убедитесь, что выбрана модель `deepseek-v4-flash` (установлена по умолчанию).
6. Нажмите **«⚡ Проверить»** для проверки связи с сервером.
7. Нажмите **«💾 Сохранить»**.

*Примечание: Вы также можете единожды прописать ключ в `config.py` в поле `ELYSIUM_API_KEY = "sk-..."`.*

## ⚙️ Установка и Запуск

1. **Python 3.9+**.
2. **ffmpeg:** Убедитесь, что в папке `Live2DAssistant/ffmpeg` присутствуют `ffmpeg.exe` и `ffprobe.exe`.
3. **Запуск:** Просто дважды кликните по файлу **`run.bat`**.

Лаунчер `run.bat` автоматически выполнит все необходимые действия:
- Активирует виртуальное окружение `venv` (или использует системный Python).
- Проверит библиотеки из `requirements.txt`.
- Запустит сервер `python_server.py` через Uvicorn.
- Откроет приложение в вашем браузере.

## 🛠️ Команды Live2D для промптов

Вы можете научить ассистента управлять своей моделью, вставляя в системный промпт или отправляя в сообщениях следующие команды:

-   `【Киваю головой】` — кивок в знак согласия/одобрения
-   `【Махаю головой】` — покачивание головой при несогласии/сомнении
-   `【Посмотреть влево】` — отвести взгляд влево
-   `【Посмотреть вправо】` — отвести взгляд вправо
-   `【Посмотреть вверх】` — посмотреть вверх
-   `【Посмотреть вниз】` — опустить взгляд вниз
-   `【Слежу за курсором】` — следить за курсором мыши
-   `【Голова влево】` — наклон головы влево
-   `【Голова вправо】` — наклон головы вправо
-   `【Закрыть левый глаз】` — подмигнуть левым глазом
-   `【Закрыть правый глаз】` — подмигнуть правым глазом

В редакторе ассистента добавлена кнопка **«✨ Вставить команды 【】»**, которая мгновенно добавляет готовый шаблон с инструкциями по командам в системный промпт. Также доступна кнопка **«📄 Из файла»** для загрузки промпта из `system_prompt.txt`.

## 🔌 Связь двух локальных серверов (чат + сайт с шашками)

Маршрут для интеграции внешних сайтов/игр с ассистентом:
- `POST /api/bridge/chat` на сервере ассистента (порт `5000`)
- Поддерживает передачу `game_context` для анализа текущей партии нейросетью.

## 📂 Структура проекта

```
/Live2D-Assistant/
|-- /ffmpeg/            # Исполняемые файлы ffmpeg
|-- /static/
|   |-- /Live2d_Models/ # Live2D модели
|   |-- /Live2d_avatars/# Загруженные аватары
|   |-- /silero_models/ # Файлы моделей Silero TTS
|   |-- script.js       # Логика чата и вкладки API
|   |-- edit_assistant.js# Логика страницы редактора
|   |-- style.css       # Стили интерфейса
|-- /templates/
|   |-- base.html       # Базовый HTML-шаблон с навигацией
|   |-- index.html      # Главная страница чата с вкладкой настроек API
|   |-- edit_assistant.html # Страница редактора ассистента
|-- app.py              # Основная логика, API-клиенты Elysium AI, маршруты
|-- python_server.py    # Точка входа сервера (FastAPI + Uvicorn)
|-- config.py           # Конфигурация API (Elysium AI, Silero, Live2D)
|-- system_prompt.txt   # Базовый системный промпт с командами Live2D
|-- requirements.txt    # Список библиотек
|-- database.db         # Локальная база данных SQLite
|-- run.bat             # Лаунчер для Windows
```
