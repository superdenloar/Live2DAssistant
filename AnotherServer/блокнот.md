# 📋 Блокнот — AnotherServer (Шашки + Live2D Widget)

## Описание

**AnotherServer** — это отдельный локальный HTTP-сервер (порт 8080), который хостит веб-игру в шашки с ботом. Во время игры рассчитывается аналитика (лучший ход, максимальная цепочка взятий, преимущество) и автоматически передаётся как контекст Live2D ассистенту через встраиваемый виджет.

---

## Архитектура

```
┌─────────────────────────────┐     ┌──────────────────────────┐
│    AnotherServer (:8080)    │     │   Main Server (:5000)    │
│                             │     │                          │
│  index.html                 │     │  app.py (Flask)          │
│  ├── checkers.js            │────▶│  ├── /api/bridge/chat    │
│  │   └► window.__ASSISTANT_ │     │  ├── /api/assistants     │
│  │      CONTEXT__           │     │  ├── /api/widget/config  │
│  └── <script widget.js>    │     │  ├── /static/widget.js   │
│       (загружается с :5000) │     │  ├── /static/widget.css  │
│                             │     │  └── Live2D models, TTS  │
└─────────────────────────────┘     └──────────────────────────┘
```

**Поток данных:**
1. Пользователь играет в шашки на `:8080`
2. `checkers.js` вычисляет аналитику и записывает в `window.__ASSISTANT_CONTEXT__`
3. Виджет (загруженный с `:5000`) при отправке сообщения читает `window.__ASSISTANT_CONTEXT__()` и отправляет данные как `game_context` в `/api/bridge/chat`
4. Основной сервер добавляет контекст в промпт LLM и возвращает ответ ассистента с озвучкой

## Внедрение виджета на любой сайт

Всего **1-2 строки HTML** в конце `<body>`:

```html
<!-- Если у сайта есть данные для ассистента (опционально): -->
<script>
  window.__ASSISTANT_CONTEXT__ = () => ({
    my_data: 'value',
    score: 42
  });
</script>

<!-- Сам виджет: -->
<script src="http://127.0.0.1:5000/static/widget.js"
        data-server="http://127.0.0.1:5000"
        data-assistant-id="1"></script>
```

### Параметры

| Атрибут              | Описание                           | Пример                       |
|---------------------|-------------------------------------|------------------------------|
| `data-server`       | URL основного сервера              | `http://127.0.0.1:5000`     |
| `data-assistant-id` | ID ассистента из основного сервера | `1`                          |

### Получение списка ассистентов

```
GET http://127.0.0.1:5000/api/assistants
```

Вернёт JSON:
```json
[
  { "id": 1, "name": "Лила", "description": "Стандартный ассистент.", "photo_url": "/static/Img/default_avatar.png" }
]
```

## Аналитика шашек

`checkers.js` экспортирует через `window.__ASSISTANT_CONTEXT__` следующие данные:

| Поле                    | Тип     | Описание                                    |
|------------------------|---------|----------------------------------------------|
| `best_move`            | string  | Оптимальный ход, например `"c3 → d4"`       |
| `max_captures_chain`   | number  | Макс. кол-во шашек, которые можно съесть за ход |
| `white_count`          | number  | Кол-во белых шашек                           |
| `black_count`          | number  | Кол-во чёрных шашек                          |
| `advantage`            | number  | Преимущество (white - black)                 |
| `move_number`          | number  | Номер текущего хода                          |
| `total_moves_available`| number  | Общее кол-во доступных ходов                 |

## Как это работает внутри

### Передача контекста
`checkers.js` после каждого хода вызывает:
```javascript
window.__ASSISTANT_CONTEXT__ = () => ({
    best_move: 'c3 → d4',
    max_captures_chain: 2,
    white_count: 11,
    black_count: 10,
    advantage: 1,
    move_number: 5,
    total_moves_available: 7,
});
```

### Виджет читает контекст
`widget.js` при отправке сообщения:
```javascript
const ctx = window.__ASSISTANT_CONTEXT__(); // вызывает функцию
fetch(SERVER + '/api/bridge/chat', {
    body: JSON.stringify({
        message: userInput,
        game_context: ctx,  // <-- передаётся как контекст
        session_id: sessionId,
        assistant_id: 1,
    })
});
```

### Сервер добавляет в промпт
```python
bridge_context = (
    "\n\n[Контекст с внешнего игрового сервера]\n"
    "- best_move: c3 → d4\n"
    "- max_captures_chain: 2\n"
    "- advantage: 1\n"
    "Используй эти данные как подсказки..."
)
```
