Быстрый старт

Ассистент встраивается одним тегом <script>. Внешний вид, голос, цвета и приветствие подтягиваются из кабинета — менять код на сайте после настройки не нужно.

  1. Создайте ассистента

    В разделе Ассистенты выберите тип: Live2D, GIF или чат-бот.

  2. Настройте характер и внешность

    Промпт, голос, модель, цвета виджета. Проверьте в превью и в студии.

  3. Вставьте код перед </body> 
    <script src="{{ server_url }}/static/widget.js"
        data-server="{{ server_url }}"
        data-assistant-id="{{ assistants[0].id if assistants else 1 }}"></script>
АтрибутЧто делает
data-serverАдрес сервера Live2D Assistant.
data-assistant-idID ассистента из кабинета.
data-openНеобязательный. "true" — открыть виджет сразу после загрузки страницы.
data-modeНеобязательный. novel или popup — переопределяет режим из настроек.

Контекст страницы

Ассистент может видеть то, что видит посетитель: товар в корзине, шаг оформления, позицию в игре. Объявите функцию window.__ASSISTANT_CONTEXT__ — виджет вызовет её перед каждым сообщением и передаст результат в модель.

window.__ASSISTANT_CONTEXT__ = () => ({
  'Страница': 'Корзина',
  'Товаров в корзине': cart.items.length,
  'Сумма заказа': cart.total + ' ₽',
  'Бесплатная доставка от': '3000 ₽'
});
{{ icon('sparkles', 18) }}Ассистенту сказано опираться только на эти данные и не придумывать цифры. Чем точнее контекст — тем умнее ответы. Ключи можно писать по-русски: так модели проще.

JS API виджета

После загрузки виджет создаёт объект window.LW. Через него сайт может открыть окно, задать вопрос от имени посетителя или заставить персонажа что-то сказать.

МетодОписание
LW.open() / LW.close()Открыть или свернуть виджет.
LW.ask(text)Отправить вопрос, как будто его написал посетитель. Возвращает Promise с ответом.
LW.say(text)Персонаж произносит текст без запроса к ИИ (подсказки, реакции на события).
LW.setContext(obj)Задать контекст объектом вместо функции.
LW.callOperator()Переключить посетителя на живого оператора.
LW.on(event, fn)События: ready, open, close, message, status.
// Подсказка, когда посетитель долго смотрит на тарифы
setTimeout(() => window.LW && LW.say('Если сомневаетесь с тарифом — спросите меня!'), 20000);

// Кнопка «Спросить ассистента» на странице
document.querySelector('#help').onclick = async () => {
  LW.open();
  const answer = await LW.ask('Какой ход сейчас лучше?');
  console.log(answer.text);
};

Живой оператор

Посетитель может в любой момент нажать кнопку с гарнитурой в шапке виджета или просто написать «позовите оператора». Диалог получит статус «Ждёт оператора» и поднимется наверх в разделе Диалоги, а в меню загорится счётчик.

Пока диалог у оператора, ассистент молчит: сообщения посетителя приходят вам, ваши ответы появляются у посетителя в окне виджета с подписью «Оператор». Кнопка «Вернуть ассистенту» снова включает ИИ — он увидит в истории, что ответил человек.

Команды движений

Ассистент вставляет в ответ команды в скобках 【】. Они не показываются посетителю и не озвучиваются — только исполняются персонажем. GIF-аватары понимают кивок, покачивание, наклоны и взгляды.

REST API

Виджет использует эти же методы — их можно вызывать со своего бэкенда.

МетодОписание
POST/api/bridge/chatСообщение ассистенту. JSON: assistant_id, session_id, message, game_context. Ответ: ai_text, audio_url, status.
GET/api/widget/config/<id>Настройки внешности и виджета.
POST/api/widget/handoffПозвать оператора (cancel: true — отменить).
GET/api/widget/pollНовые ответы оператора: ?assistant_id=&session_id=&after=.
GET/api/assistantsСписок ассистентов.
const r = await fetch('{{ server_url }}/api/bridge/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ assistant_id: 1, session_id: 'user-42', message: 'Где мой заказ?' })
});
const { ai_text, audio_url } = await r.json();

Вопросы

Виджет не появился на сайте

Проверьте, что сервер ассистента запущен и адрес в data-server открывается из браузера посетителя. Ошибки видны в консоли браузера с префиксом [Widget].

Нет звука

Браузеры запрещают звук до первого клика по странице. После любого взаимодействия голос заработает. Также проверьте голосовую модель в редакторе ассистента.

Ассистент отвечает «API ключ не настроен»

Укажите ключ в Настройках и нажмите «Проверить подключение».
